## Custom NPCs: Ultimate

This is an unofficial port of Noppes's [CustomNPCs](https://www.curseforge.com/minecraft/mc-mods/custom-npcs) mod to the newer versions of Minecraft.

For now, this version adds advanced vanilla Mob Spawner configuration capabilities for creators.

<details>
<summary><b>FEATURES (Click to expand)</b></summary>

### 🛠️ Spawner Expansion (New in Ultimate)
- **Visual Config GUI**: Shift-Right-Click on any Mob Spawner with the NPC Wand to configure it.
- **Spawner Settings**: Easily adjust delay range, spawn count, player range, nearby entity caps, and range.
- **Custom Light Rules**: Toggle spawners to **Friendly** (ignores light rules for daylight spawning) or **Hostile** (block light 0-7, ignoring sky limits to support nighttime spawning in open plains).
- **Group Spawner wave logic**: Spawn entities in waves. Spawners pause until the previous group is completely defeated.
- **Guaranteed Spawn Size**: Spawns are retried if block collisions occur, falling back to the spawner block coordinates if needed to guarantee the full group size spawns.
- **Return-To-Start Disablement**: NPCs spawned from vanilla spawners have their return-to-start AI disabled to prevent them from crowding on top of the spawner block.

---

### 🎭 Original CustomNPCs Features
- **Custom Models & Skins**: Create unique characters with custom scaling, parts, and animations.
- **[Geckolib](https://modrinth.com/mod/geckolib)**: Geckolib models works now correcly.
- **Roles & Jobs**: Set NPCs as Traders, Followers, Guards, Bards, Bankers, Transporters, and more.
- **Interactive Quests & Dialog**: Build branching conversation trees and quest systems.
- **Factions & Scripts**: Define alignments and script custom JVM behaviors.

*For details, guides, and scripting examples, check the [Official Custom NPCs: Ultimate Wikis](https://kodevelopment.nl/minecraft/customnpcs/wiki).*
